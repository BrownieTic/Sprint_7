# Sprint_7

Автотесты REST API сервиса «Самокат» на Python с использованием `pytest`, `requests` и `Allure`.

## Что проверяют тесты

### Тесты курьеров — `tests/test_сourier_api.py`

Проверяется:

- создание курьера со всеми обязательными данными;
- создание курьера с уже существующим логином;
- создание курьера без логина;
- создание курьера без пароля;
- авторизация курьера с корректными данными;
- авторизация без логина;
- авторизация без пароля;
- авторизация с неправильным логином;
- авторизация с неправильным паролем;
- авторизация с неправильными логином и паролем.

### Тесты заказов — `tests/test_order_api.py`

Проверяется:

- создание заказа с разными вариантами параметра `color`;
- получение списка заказов без параметров и с различными параметрами;
- корректность структуры ответа списка заказов;
- фильтрация заказов по `courierId`;
- фильтрация заказов по `nearestStation`;
- корректность параметров `limit` и `page`;
- совместная работа фильтров и параметров пагинации.

## Структура проекта

```text
Sprint_7/
├── api/
│   ├── courier_api.py           # HTTP-методы API курьеров
│   └── order_api.py             # HTTP-методы API заказов
├── conftest.py                  # Фикстуры: подготовка и очистка тестовых данных
├── data.py                      # Постоянные тестовые данные и ожидаемые форматы
├── randomizer.py                # Генерация случайных тестовых данных
├── urls.py                      # Базовый адрес и URL эндпоинтов API
├── requirements.txt             # Зависимости проекта
├── README.md                    # Описание проекта
└── tests/
    ├── test_сourier_api.py      # Тесты API курьеров
    └── test_order_api.py        # Тесты API заказов
```

## Организация кода

- Классы `CourierAPI` и `OrderAPI` инкапсулируют HTTP-запросы к соответствующим эндпоинтам.
- Фикстуры из `conftest.py` подготавливают данные для тестов и выполняют очистку после них; для запросов они используют API-классы.
- Тесты в каталоге `tests/` описывают сценарии и проверяют ответы сервера.
- `data.py` содержит общие тестовые данные, а `randomizer.py` — генератор случайных данных для тестов.
